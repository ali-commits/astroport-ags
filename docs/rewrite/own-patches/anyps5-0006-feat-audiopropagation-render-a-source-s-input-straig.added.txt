Subject: [PATCH] feat(audiopropagation): render a source's input straight into
 the bed's first channel

Sources had no paths and rendered silence, so every sound the title sends
through propagation was dropped (ASTRO BOT: the haptics of the character's
contact with the world). Following KytyPS5's direct mode: the source input set
with attribute 4 is written into channel 0 of the output bed, which is
cleared first, and the input is used once.

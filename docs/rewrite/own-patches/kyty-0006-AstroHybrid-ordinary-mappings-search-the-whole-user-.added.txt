Subject: [PATCH] AstroHybrid: ordinary mappings search the whole user range
 when the host donated memory

int22 ends the search for free guest ranges at the AMM window (kAmmWindowBase,
0xec00000000). AnyPS5 donates its 64 GiB guest window at exactly that address,
so Astro Bot's first non-fixed direct-memory map (3.2 GiB) found no range and
failed with ENOMEM. With host placeholders the search covers the user range to
its end again, as before int22; the AMM calls are AnyPS5's own in the hybrid.

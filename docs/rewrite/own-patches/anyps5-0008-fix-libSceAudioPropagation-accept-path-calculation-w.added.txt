Subject: [PATCH] fix(libSceAudioPropagation): accept path calculation without
 rays and audio path entries

Astro Bot's Slo-Mo Casino calls sceAudioPropagationSourceCalculateAudioPaths with no rays
(order 1, 36 paths) and hands paths to sceAudioPropagationSourceSetAudioPaths; both failed
or threw, and the game crashed on entering the level. Without propagation there are no paths
to compute, and sources render their input directly, so both now succeed.

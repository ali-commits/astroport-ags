# Our own earlier engine changes

These files hold the lines that Ali and Claude added to the engines before the rewrite, one file per
commit: the commit message, then for each file the added lines only (`+`), with the line number where
each group started. Context and removed lines are left out on purpose, because they belonged to code
that is no longer in the tree.

They are reference material for re-homing these features on the new bridge (design.md, decision 3).
The surrounding code they were written against is gone, so read them for what they do, not as patches
to apply.
